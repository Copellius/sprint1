# Bookmark Landing Page

## Description
This project is a landing page for a bookmark manager browser extension. It provides a clean and simple interface to promote downloading the extension for different browsers such as Chrome, Firefox, and Opera. It includes sections like features, frequently asked questions, and a contact form.

## Technologies Used
**Frontend**
- HTML5
- CSS3 (with variables and media queries)
- SCSS (compiled to CSS)
- Tailwind CSS (used in the third branch)

## Accessibility
- Semantic structure using `role` and `aria-*` attributes
- Accessible navigation adapted for mobile devices

## Project Installation

Choose a folder where you want to clone the repository.

Clone the repository:
```bash
git clone https://github.com/Copellius/sprint1
```

Enter the project directory:
```bash
cd sprint1
```

Fetch all available branches:
```bash
git fetch --all
```

Switch to the desired branch:

### Vanilla implementation
```bash
git checkout feature/vanilla-implementation
```

### Sass implementation
```bash
git checkout feature/sass-implementation
```

### Tailwind implementation
```bash
git checkout feature/tailwind-implementation
```

Open the `index.html` file in your browser.
